Support

Where to report bugs, request features and get help.

Bugs and ideas

Use the bug-report form for reproducible incorrect behaviour. Include the subshell version (Settings › Help & about), Android version, device model and clear steps.

Report a bug Request a feature

A report from the app

Settings › Advanced › Diagnostics can create a privacy-safe report of recent app events to attach to an issue. It contains no screenshots, typed text or Reddit content, and nothing is sent unless you choose to.

Before you post

Sanitize screenshots and logs.

Remove usernames, message contents, credentials, tokens, cookies and other private account information before attaching anything to a public issue.

Security issues

Security vulnerabilities must not be filed as public issues. Use the private security-reporting route instead.

Security reporting

Help yourself first

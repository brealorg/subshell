Guide

Get started

Install the beta, get your Reddit Client ID once, and sign in. About ten minutes.

Android 8.0+ About ten minutes

Before you start

  • An Android phone, tablet or foldable with Android 8.0 or newer.
  • A Reddit account.
  • About ten minutes. The Client ID step below is done once per installation.

1. Install the beta

Download the Subshell-<version>.apk file from the latest GitHub release and open it. Android asks you to allow installing apps from your browser or file manager the first time; allow it for that app only.

Each release also has a .sha256 file. To check the download on a computer, compare it with sha256sum Subshell-<version>.apk. The in-app update dialog shows the same checksum.

Updates

subshell checks for a new beta about twice a day and tells you when one is ready. It opens the release page; it never downloads or installs an APK by itself. Install the new APK over the old one to keep your settings and sign-in.

2. Get your Reddit Client ID

Reddit only lets an app sign you in when it presents a Client ID. subshell does not ship a shared one, so you get your own once, through RedReader's sign-in, and paste it into subshell. The app walks you through the same steps.

  1. Install or open RedReader RedReader is used once to create the Reddit authorization that gives you the Client ID subshell needs. It is on Google Play and F-Droid.
  2. Sign in to Reddit in RedReader Complete RedReader's normal Reddit sign-in and authorize it when Reddit asks.
  3. Open Reddit's authorization email Find the line labeled App ID. The value beside App ID is the Client ID you will paste into subshell.
  4. Paste it into subshell Choose I already have a Client ID, paste only the App ID value and tap Save Client ID.
Where it is kept

Your Client ID is kept in encrypted no-backup storage on this device and isn't included in subshell settings backups.

3. Sign in

Tap Connect Reddit. Reddit's own sign-in page opens inside subshell; sign in and authorize. subshell keeps only the session Reddit hands back, never your password. You can add more accounts later from Settings and switch between them.

4. Make it yours

  • On first start subshell asks which side your thumb controls and floating buttons should favour.
  • Choose a backup folder outside the app, so your setup survives reinstalling. A folder named subshell Backups in Documents works well.
  • Optional: let Reddit links open in subshell. Android decides which apps open web links, so subshell takes you to the system page; turn on Open supported links and pick the Reddit addresses.
  • Settings is searchable and sorted by area: theme and text size, navigation and swipe actions, feeds and filters, video, comments, notifications and backups.

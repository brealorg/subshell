Privacy

How Subshell handles app and website data.

Effective 5 September 2026 Android + website

Android app

When you choose to connect a Reddit account, authentication is handled through Reddit. OAuth credentials are stored in app-private encrypted storage backed by Android Keystore and are not included in Subshell settings backups.

Subshell may process account identifiers, Reddit listings, posts, comments, subscriptions, messages and actions you explicitly request. Routine Reddit requests are exchanged between the app and Reddit.

For offline and continuity features, the app may keep Reddit content, account metadata and settings in app-private local storage. User-selected backups and downloaded media are separate files controlled by the user.

Project data collection

Subshell does not use advertising or targeted tracking, and the project does not sell personal data.

This website

The Subshell website is a static GitHub Pages site. It uses client-side JavaScript for the screenshot gallery and optional presentation features. If dynamic device colour is selected, the preference is stored locally in the browser under subshell.palette.

The site does not use project analytics, advertising, tracking forms or project-set cookies. GitHub may process request metadata needed to host and secure GitHub Pages under GitHub's own policies.

Third-party services

Reddit processes information when the app connects to Reddit services. GitHub processes information required to host the public project and website. Their own terms and privacy policies govern that processing.

Retention and deletion

Logging out removes the corresponding local authentication session. Clearing app storage or uninstalling removes app-private local data. User-selected backups and downloaded media must be removed from their storage locations by the user.

Questions

Privacy questions can be raised through the project support channels. Do not post credentials, tokens, private messages or other sensitive account data in a public issue.

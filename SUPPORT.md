# Support

For application bugs, use the GitHub bug-report form.

For feature requests, use the feature-request form.

When reporting a problem:

- include the subshell version;
- include Android version and device model when relevant;
- describe the steps that reproduce the problem;
- remove usernames, message contents, tokens, cookies, and other private
  account information from screenshots and logs.

Security vulnerabilities must not be filed as public issues. See
`SECURITY.md`.

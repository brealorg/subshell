# Security policy

## Reporting a vulnerability

Do **not** report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository:

**Security → Advisories → Report a vulnerability**

Please include enough information to reproduce and assess the issue, but
do not include credentials, Reddit access tokens, refresh tokens, session
cookies, passwords, private messages, or other personal account data.

## Supported builds

Before the first public beta there is no publicly supported build.

After public beta publication, security fixes will target the newest
public beta/release unless a release note explicitly states otherwise.

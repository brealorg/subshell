# subshell

Public project, release, and issue-tracking home for **subshell**, an
independent Android Reddit client.

The first public beta is being prepared.

## Public links

- Website: https://brealorg.github.io/subshell/
- Releases: https://github.com/brealorg/subshell/releases
- Issues: https://github.com/brealorg/subshell/issues

## Repository scope

This repository currently contains the public project infrastructure,
documentation, GitHub Pages site, issue tracking, and release records.

The Android application source code is **not published in this repository
at this stage**.

Public beta APKs will be distributed through GitHub Releases after they
have passed the project's release qualification and signing gates.

## Independence

subshell is an independent project and is not affiliated with, endorsed
by, or sponsored by Reddit.
